# RDM dialogue speakers

Local review set: 33 transparent PNG portraits covering source dialogues 1–50. Related topic variants reuse the same person. Nothing in this set has been published.

`manifest.json` records each identity, source dialogue numbers, image path and individual generation description. `content/speakers.js` supplies the matching runtime mapping. Keep both mappings aligned when changing an assignment. Future dialogue content must retain its original `source.dialogue` number so its reserved portrait loads automatically.

Review all portraits at `/speaker-gallery.html`. The current trainer uses the assigned portraits for dialogues 1–10; the other portraits are saved here for future inclusion.

## Generation recipe

Reference: `railway.png`, the approved first portrait. Generate one transparent PNG per identity, replacing ROLE below with its manifest description:

Create ONE transparent speaker portrait matching the attached approved RDM railway clerk's richly detailed illustrated storybook realism and framing, but a DISTINCT person and profession: ROLE. Warm professional direct eye contact, natural human proportions, large clear face. Deep bright turquoise, vermilion red-orange and antique gold palette, rich tactile textures, gold piping. Centered square waist-up portrait behind short curved teal counter with botanical gold engraving and small red flowers at bottom corners. Profession-specific clothes and props, do not copy the railway uniform or original woman's face. No letters, words, numbers, watermark or scenery. Genuine alpha transparency outside person and counter; generous safe margin, complete head and hands. One character only.
